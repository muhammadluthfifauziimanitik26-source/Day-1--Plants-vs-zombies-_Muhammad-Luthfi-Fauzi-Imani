# Day 1 - Plants vs Zombies

Nama Peserta:Muhammad Luthfi Fauzi Imani

Deskripsi Repository
Repository ini berisi hasil latihan dan dokumentasi dari workshop "Building with AI, Managing Change with GitHub". Di dalamnya terdapat proyek sederhana (Plants vs Zombies) yang dibuat dengan bantuan AI, lalu dikelola menggunakan Git dan GitHub.

Tujuan Repository
- Mempraktikkan alur version control dengan Git dan GitHub.
- Mendokumentasikan proses belajar dan hasil dari workshop.
- Menjadi contoh penggunaan repository, commit, dan push ke GitHub.

Kegiatan Workshop yang Didokumentasikan
Judul:Building with AI, Managing Change with GitHub
Pemateri:Nugi Farhan (Senior Product Designer)

Materi yang dipelajari:
1. Prompt Engineering: menyusun prompt dengan struktur Role, Task, Context, dan Format agar hasil AI lebih tepat.
2. Git vs GitHub: Git adalah sistem version control untuk melacak perubahan kode secara lokal, sedangkan GitHub adalah platform online untuk menyimpan repository dan berkolaborasi.
3. Git Workflow: Working Directory, Staging Area, dan Git Directory (Repository).
4. Setup: instalasi Git, konfigurasi identitas, VS Code, dan SSH key untuk koneksi ke GitHub.
5. Perintah dasar Git: `git init`, `git clone`, `git add`, `git commit`, `git push`, `git pull`.

Alur kerja yang dipraktikkan:
1. Membuat aplikasi dengan bantuan AI menggunakan prompt yang terstruktur.
2. Menambahkan proyek ke Git.
3. Commit dan push ke GitHub.
4. Melakukan perubahan, lalu commit dan push kembali.
